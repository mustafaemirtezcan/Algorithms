# 🧑‍💻Algorithms

Java assignments on algorithm design and analysis. Every folder has the assignment PDF, input files and the source code.

- **PA1 - Sorting:** comb, insertion, shaker, shell and radix sort compared on a traffic-flow dataset, with a runtime report.
- **PA2 - Dynamic Programming & Greedy:** maximizes collected scrolls with DP and minimizes the number of ships with a greedy approach.
- **PA3 - Alien Flora:** reads genomes from XML and groups them into clusters by how they connect.
- **PA4 - Graphs:** the fastest route around campus using walking and cart lines, plus a project scheduler that orders tasks by their dependencies.
