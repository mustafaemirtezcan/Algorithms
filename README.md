# Algorithms

Algorithm assignments in Java. Each folder contains the assignment description, input files and the source code.

- **PA1:** Comparison of comb, insertion, shaker, shell and radix sort, with a runtime report.
- **PA2:** Dynamic programming and greedy solutions to two optimization problems.
- **PA3:** Clustering genomes read from XML.
- **PA4:** Shortest-route search on a campus network and dependency-based project scheduling.
